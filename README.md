# Agenda Inteligente

Nova implementação da Plataforma Unificada, adaptada para hospedagem compartilhada.

A aplicação preservará o frontend React + TypeScript + Vite e substituirá o backend Node.js/PGlite por PHP 8.2 e MySQL/MariaDB.

O desenvolvimento será conduzido por branches e pull requests, conforme o planejamento arquitetural registrado em `docs/architecture/`.
